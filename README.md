Student Management System (C++)

About the Project

The Student Management System is a console-based mini project developed using C++ and Object-Oriented Programming (OOP) concepts. It is designed to manage student information in a simple and organized way.

The system allows users to add, display, search, update, and delete student records through a menu-driven interface.

This project demonstrates the practical implementation of important OOP concepts such as classes, objects, encapsulation, inheritance, polymorphism, abstraction, constructors, and destructors.

Project Objectives

- To develop a simple Student Management System using C++.
- To understand and implement Object-Oriented Programming concepts.
- To store and manage student information.
- To perform basic operations on student records.
- To improve programming and problem-solving skills.

Features

1. Add Student: Add a new student with roll number, name, age, course, and marks.
2. Display Students: Display all stored student records.
3. Search Student: Find a student using their roll number.
4. Update Student: Update the course and marks of an existing student.
5. Delete Student: Remove a student record using the roll number.
6. Automatic Grading: Calculate grades according to student marks.
7. Duplicate Prevention: Prevent duplicate student roll numbers.
8. Input Validation: Handle incorrect numeric input.

How to Run the Project

Step 1: Download or clone this repository.

Step 2: Open the project folder in your code editor or terminal.

Step 3: Compile the program using:

g++ -std=c++11 student_management.cpp -o student_management

Step 4: Run the program.

For Linux / macOS:

./student_management

For Windows:

student_management.exe

Limitations

- Student records are stored in memory only.
- Records are lost when the program is closed.
- Names and course names are currently entered as single words.
- The project uses a console-based interface.
